# Connecting Workforce website

Responsive multi-page static website using HTML, CSS and vanilla JavaScript.

## Pages
Home, Workforce, Employers, Cleaning Services, Technology & Devices, Workwear & PPE, Company Printing, Jobs, Events, Employment Resources, Store, About, Founder & Purpose, Contact, Privacy, Accessibility, Terms & Conditions, Website Feedback, Sitemap and 404.

## Preview locally or in GitHub Codespaces
Run `python3 -m http.server 8000 --bind 0.0.0.0` and open forwarded port 8000.

## Before public launch
- Contact and feedback forms are preview-only and do not transmit or store submissions. Configure a secure form endpoint and test it before use.
- Store catalogue is enquiry-only. No checkout or payment processing is enabled.
- Privacy and terms are draft website copy and should be reviewed against actual operations, data practices and business details before launch.
- Job and event pages provide general links; they do not claim specific vacancies or events are current. Add individual listings only after verifying the original source and date.
- External photos are referenced from Pexels image CDN and require an internet connection. The company-printing T-shirt concept is an original local SVG illustration and is not a photograph of a completed customer order.
- The site is an independent private business website and does not imply government affiliation or endorsement.
- Test keyboard navigation, screen readers, contrast, zoom, mobile layout and all links before launch.
