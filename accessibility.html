ACCESSIBILITY

Our accessibility commitment

Connecting Workforce aims to make this website clear, responsive and accessible. We are working toward WCAG 2.2 AA as a design target; this is an aim, not a claim of completed independent certification.

We aim to support

  • Keyboard navigation and visible focus
  • Screen-reader-compatible headings, labels and landmarks
  • Readable text, sufficient contrast and browser zoom
  • Responsive layouts for mobile and desktop
  • Descriptive image alternatives and meaningful link text
  • Clear form labels, instructions and error messages
  • Reduced-motion preferences where animation is used

Report an accessibility barrier

If something prevents you from using the website, please describe the page, the task you were trying to complete and the assistive technology or browser involved, if you are comfortable sharing that information.

Send website feedback

Accessibility testing should be completed with keyboard-only navigation, screen readers, zoom, mobile layouts and automated checks before public launch.
